## O que o exame cobra neste bloco

S3 = objeto (HTTP, ilimitado, classes). EBS = disco da instância (bloco, uma AZ). EFS = arquivo compartilhado (várias AZs, Linux). Instance Store = temporário. Palavras-chave de classe S3 (Standard, IA, Glacier…) caem muito.
