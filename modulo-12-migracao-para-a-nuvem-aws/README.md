## O que o exame cobra neste bloco

Decorar o **R** certo: Rehost (lift-and-shift), Replatform, Refactor/Re-architect, Repurchase, Retain, Retire, Relocate. DMS = banco com pouca downtime. Snow Family = petabytes sem esgotar a internet. CAF = pessoas + processo + tecnologia, não só lift-and-shift.
