## Objetivos

Ao revisar este módulo, você deve conseguir:

- Explicar o que é Amazon EC2 e quando usá-lo
- Classificar famílias de instância (geral, compute, memória, armazenamento, acelerada)
- Escolher como provisionar (Console, CLI, SDK, CloudFormation, Elastic Beanstalk)
- Distinguir On-Demand, Savings Plans, Reserved Instances, Spot e Dedicated Hosts
- Separar scaling vertical de horizontal e o papel do EC2 Auto Scaling
- Posicionar Elastic Load Balancing e os tipos de load balancer
- Relacionar SQS, SNS e o desacoplamento de aplicações
