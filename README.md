# AWS Cloud Practitioner Essentials

Material de estudo para o curso **AWS Cloud Practitioner Essentials (Português)** no Skill Builder, alinhado ao exame **AWS Certified Cloud Practitioner (CLF-C02)**.

Não é transcrição do curso. Cada pasta resume o que cai na prova, força recall ativo e aponta as pegadinhas mais comuns.

## Como estudar

Para cada módulo:

1. Assista e faça a avaliação no Skill Builder.
2. Leia o `resumo.md` (5–10 min).
3. Responda os `flashcards.md` sem olhar a resposta.
4. Faça o `quiz.md` como se fosse prova.
5. Anote erros em `pegadinhas.md`.

Quando terminar um módulo no Skill Builder, diga no chat: **“terminei o módulo X”** (e, se quiser, cole dúvidas ou erros da avaliação). A pasta correspondente é preenchida no mesmo formato.
