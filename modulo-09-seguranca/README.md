## Tópicos previstos

- Revisão do modelo de responsabilidade compartilhada
- IAM: usuários, grupos, roles, políticas, MFA
- Proteção do usuário root
- Princípio do menor privilégio
- Proteção de rede e aplicações (WAF, Shield, Security Groups)
- Proteção de dados (criptografia em trânsito e em repouso, KMS, Secrets Manager)
- Detecção e resposta (GuardDuty, Inspector, Security Hub — visão)

## O que o exame cobra neste bloco

Root só para poucas tarefas; MFA no root. Role ≠ user (credencial temporária). Least privilege. Shield vs WAF. Encryption at rest vs in transit. Este módulo vale a revisão extra: é o domínio mais pesado depois de tecnologia.
