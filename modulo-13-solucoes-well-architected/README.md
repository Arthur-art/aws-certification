## O que o exame cobra neste bloco

Os **seis pilares**: excelência operacional, segurança, confiabilidade, eficiência de performance, otimização de custo, **sustentabilidade**. Saber o que cada pilar prioriza. Serviços de nicho só no nível “qual serviço para WorkSpaces / IoT Core / Amplify”, sem profundidade de implementação.
