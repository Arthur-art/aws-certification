## Objetivos

Ao revisar este módulo, você deve conseguir:

- Definir computação em nuvem (on-demand + pay-as-you-go)
- Distinguir implantação em nuvem, on-premises e híbrida
- Listar os benefícios da Nuvem AWS
- Explicar Região e Availability Zone em uma frase cada
- Separar o que é responsabilidade da AWS vs do cliente
