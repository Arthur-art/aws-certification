## O que o exame cobra neste bloco

SQL + joins + esquema fixo → RDS/Aurora. Key-value em escala sem servidor para gerenciar → DynamoDB. Analytics em data warehouse → Redshift. Cache na frente do banco → ElastiCache. Multi-AZ no RDS = alta disponibilidade, não é backup sozinho.
